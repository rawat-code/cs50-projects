# CS50 AI — Projects

Projects from [CS50's Introduction to Artificial Intelligence with Python](https://cs50.harvard.edu/ai/) (Harvard OpenCourseWare). Each project has its own folder and its own git tag.

## Projects

| Week | Topic | Project | Tag | What it does |
|------|-------|---------|-----|--------------|
| 0 | Search | `degrees` | `week0-degrees` | Finds the shortest path between two actors through shared movies |
| 0 | Search | `tictactoe` | `week0-tictactoe` | Unbeatable Tic-Tac-Toe AI using minimax |
| 1 | Knowledge | `knights` | `week1-knights` | Solves Knights and Knaves puzzles with propositional logic |
| 1 | Knowledge | `minesweeper` | `week1-minesweeper` | Minesweeper AI that infers safe cells and mines from knowledge |
| 2 | Uncertainty | `pagerank` | `week2-pagerank` | PageRank via sampling and iterative computation |
| 2 | Uncertainty | `heredity` | `week2-heredity` | Bayesian network for gene and trait probabilities |
| 3 | Optimization | `crossword` | `week3-crossword` | Crossword generator as a constraint satisfaction problem |
| 4 | Learning | `shopping` | `week4-shopping` | k-nearest-neighbor model predicting shopping behavior |
| 4 | Learning | `nim` | `week4-nim` | Nim agent trained with Q-learning |
| 5 | Neural Networks | `traffic` | `week5-traffic` | CNN classifying traffic sign images |
| 6 | Language | `parser` | `week6-parser` | Context-free grammar parser extracting noun phrases |
| 6 | Language | `attention` | `week6-attention` | Masked language model and attention visualization with BERT |

## Tech

Python, NumPy, pandas, scikit-learn, TensorFlow, Transformers

## Running a project

```bash
git clone <repo-url>
cd cs50-projects/<project>
pip install -r requirements.txt   # if the project has one
python <project>.py
```

Completed for learning. Projects were submitted through CS50's own `submit50` and graded with `check50`.
